# Diwali Cracker Order

Shared order sheet for the Goat Crackers (djcrackers.com) price list: photos, YouTube search links, final prices, and quantity pickers for Mansoor, Nagendra and Santosh. Picks save to a Firebase Realtime Database (address in `config.js`) and sync live across browsers. The PDF button downloads the order grouped by category with each person's quantities and totals.

Hosted with GitHub Pages from the `main` branch.
